🥬 Digital Gardener

Digital Gardener — это лёгкое и бесплатное портативное приложение для Windows с открытым исходным кодом, которое наводит порядок на вашем компьютере: очищает мусор, находит забытые файлы и дубликаты, управляет автозагрузкой и процессами, разблокирует занятые файлы и показывает характеристики системы. Всё в одном .exe, без установки, с встроенным .NET в .exe без рекламы и без отправки данных в интернет, 100% на C#.

Приложение ничего не удаляет и не восстанавливает без ваших действий/разрешений, в Цивровом Садовнике версии 1.3.0 вы всё делаете сами и страшного в этом ничего нет.

✨ Что умеет приложение

    🗑️ Очистка Temp и Downloads — удаление временных файлов и содержимого загрузок

    🌐 Кэш браузеров — Chrome, Edge, Firefox, Opera

    🎮 Игровой кэш — DirectX, Steam, NVIDIA, AMD, Epic

    📦 Архивы и установщики — поиск забытых .zip, .rar, .7z, .iso, .exe, .msi старше 30/60/90/180 дней

    🔍 Поиск дубликатов файлов — по всему диску или в выбранной области

    📁 Неиспользуемые файлы, папки и приложения — забытые за 30/60/90/180 дней

    🚀 Управление автозагрузкой — отключение лишнего в один клик

    ⚙️ Мониторинг процессов — с графиками CPU/RAM в реальном времени и возможностью завершения

    🗑️ Удаление программ — штатное удаление через систему

    🔓 Разблокировка занятых файлов — освобождение файлов, заблокированных другими процессами

    💻 Информация о системе — CPU, RAM, GPU, ОС

    📋 Журнал и отчёт — отдельный лог ошибок для каждой сессии, удобный для баг-репортов

    💽 Выбор диска в футере — показывает свободное место и влияет на 3 вкладки: «Неиспользуемые», «Архивы», «Дубликаты (весь диск)»

🖥️ Системные требования

    Windows 10/11, 64-бит

    Права администратора (UAC)

    Установка не нужна — .NET встроен в .exe

📥 Как установить и запустить

    Скачайте DigitalGardener_v1.3.0.zip из раздела Releases

    Распакуйте в любую папку

    ПКМ по DigitalGardener.exe → Запуск от имени администратора

    Согласитесь с UAC

    ⚠️ SmartScreen → «Подробнее» → «Выполнить в любом случае»
