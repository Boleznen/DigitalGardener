🌱 Digital Gardener v1.3.0 — Стабильность и удобство

Что нового

    📦 Новая вкладка «Архивы и установщики» — ищет «забытые» архивы (.zip, .rar, .7z, .iso) и установщики (.exe, .msi), которые не изменялись дольше 30/60/90/180 дней. Их можно удалить в корзину или перенести в архив приложения.
    💽 Выбор диска в футере — показывает свободное место на выбранном диске (например: «C: — свободно 27,10 ГБ из 199,49 ГБ»). Влияет на 3 вкладки: «Неиспользуемые файлы», «Архивы и установщики» и «Поиск дубликатов (весь диск)».
    📋 Отдельный лог ошибок для каждой сессии — формат: errors_2026-09-19_14-32-01.log. В UI всегда свежий лог, старые файлы лежат в папке DigitalGardener_Logs — удобно для баг-репортов.
    🧹 Кнопки «Очистить журнал ошибок» и «Открыть папку логов» — управление логами стало удобным.
    📖 Помощь выросла до 16 разделов — добавлен раздел «💽 Выбор диска», объясняющий, что где сканируется.
    📂 Кнопки «Открыть архив» и «Открыть корзину» в шапке приложения.
    ⏳ Оверлей «Подождите» с прогрессом — для удаления, архивации и поиска дубликатов.
    🧹 Кнопки «Очистить список» во всех вкладках.

Улучшено

    ⚡ Архивация стала надёжнее — файлы переносятся в папку DigitalGardener_Archive, так-же без сжатия. Если файл занят другой программой — он просто пропускается, остальные переносятся. В отчёте видно: «В архив: N/M (пропущено: K)».
    📋 Журнал ошибок в UI обновляется в реальном времени — новые записи появляются снизу автоматически, без нажатия кнопки.
    💽 Автообновление свободного места на диске — раз в 15 секунд, без перезапуска.
    🎨 Тёмная тема стала единообразнее — все кнопки, поля, выпадающие списки и таблицы в одном стиле.

Убрано

    🧹 Мусорные файлы проекта — пустые заготовки и неиспользуемые классы

Основные возможности

    🗑️ Очистка Temp и Downloads
    🌐 Кэш браузеров (Chrome, Edge, Firefox, Opera)
    🎮 Игровой кэш (DirectX, Steam, NVIDIA, AMD, Epic)
    📦 Архивы и установщики (новое)
    🔍 Поиск дубликатов
    📁 Неиспользуемые файлы/папки/приложения
    🚀 Управление автозагрузкой
    ⚙️ Мониторинг процессов (с авто-обновлением)
    🗑️ Удаление программ
    🔓 Разблокировка занятых файлов
    📊 Графики CPU/RAM в реальном времени
    📋 Журнал и Отчёт (с отдельными логами по сессиям)

Системные требования

    Windows 10/11, 64-бит
    Права администратора (UAC)
    Установка не нужна — .NET встроен в .exe

Как установить

    Скачайте DigitalGardener_v1.3.0.zip ниже
    Распакуйте в любую папку
    ПКМ по DigitalGardener.exe → Запуск от имени администратора
    Согласитесь с UAC

Что под капотом

    .NET 8, WPF
    LiveChartsCore для графиков
    Иконки файлов через Windows Shell API
    Логи по сессиям: DigitalGardener_Logs/errors_YYYY-MM-DD_HH-mm-ss.log (хранится 20 последних)
